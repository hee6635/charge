# 충전 모니터 (Android)

유선/무선 충전 상태를 실시간으로 보여주는 안드로이드 앱.

## 기능
- 충전 방식 자동 구분: 유선(충전기/USB/독) · 무선
- 실시간 전압(V) · 전류(A) · 전력(W) · 배터리 온도(°C), 1초마다 갱신
- 온도 단계 표시 (정상 / 따뜻함 / 높음 / 과열 위험)
- 완충까지 예상 시간 (최근 30초 평균 전류 기준) + 시스템 예상값(Android 9+)
- 최근 5분 전력 · 온도 그래프 (누르고 있으면 그 시점 값 표시)
- 이번 충전 요약: 시간, 충전량, 평균/최대 전력, 최고 온도, 들어간 에너지(Wh)
- 배터리 정보: 상태, 기기 발열 상태, 남은 용량, 추정 전체 용량, 충전 사이클(Android 14+)
- 충전 기록 저장 + 유선 vs 무선 평균 비교
- 충전 속도 진단: 같은 잔량에서 화면 끄고 시원할 때 받았던 "원래 속도"와 비교해서, 얼마나 줄었고 왜 줄었는지를 한 문장으로 알려줌 (예: "배터리가 38°C라서 휴대폰이 일부러 약 8W 줄였어요"). 줄어든 몫을 화면 사용 / 온도 / 원인 불명으로 나눠 표시
- 변화 기록: 온도 35/37/40°C 넘음, 화면 켬/끔, 50%·80% 넘음, 전력 급변을 시간순으로 기록하고 30초 전후 전력 비교. 전력 그래프에 세로선으로 표시
- 전력·전류는 10초 평균으로 표시 (순간값은 작게)
- 백그라운드 측정 (켜고 끄는 스위치): 앱을 닫거나 화면을 꺼도 기록, 알림창에 W·온도·제한 원인 표시
- 화면 켜두기 옵션

## APK 받기
GitHub → Actions → 최신 "Build APK" 실행 → Artifacts의 `charge-monitor-apk`를 받아 압축을 풀고 설치.
(출처를 알 수 없는 앱 설치 허용 필요)

## 직접 빌드
Android Studio로 폴더를 열거나 `./gradlew assembleDebug`.

## 참고
- iPhone은 iOS가 전류/전압 정보를 앱에 주지 않아서 이런 앱을 만들 수 없음.
- 전류 단위·부호는 제조사마다 달라 자동 보정함. 일부 기기는 값이 부정확할 수 있음.
- 백그라운드 측정을 끄면 앱이 화면에 있을 때만 기록됨.
